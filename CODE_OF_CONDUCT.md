# Code of conduct

We want Echelon to be a place where people can do careful work and disagree productively.

- Be respectful. Critique the work, not the person.
- Assume good faith, and ask when something is unclear.
- Give credit, and say where ideas and code came from.
- Harassment, discrimination, and personal attacks are not acceptable.
- Keep private repositories and personal information private.

Concerns can be raised with any organization owner. Owners may remove content or access that breaks these rules.
